

# Description
This game is a top down 2D survival shooter created as practice for creating a simple game from start to finish. Created using Unity and C#, the game's mechanics are mainly inspired by games such as [Vampire Survivors](https://store.steampowered.com/app/1794680/Vampire_Survivors/).

### Objective
- Create a simple 2D game from scratch using the unity engine.
    - Learn the general process of making a game for future projects.
    - Gain experience in using the Unity Engine.
- Gain practical experience in applying OOP and general software design techniques from university and self learning.

### Status
- Main gameplay loop partially implemented.
    - Proper mob summoning system to be implemented.
- GUI system mostly implemented with some gameplay UI and menu UI missing.
- Save and load system implemented.
    - Level data storage structure to be updated as of latest version to accomodate new gameplay changes.
